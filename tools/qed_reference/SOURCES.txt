GEM4XE.car is the original system cartridge with MOUSEPORT=1 selected and a
normal DESKTOP.INF layout added in one spare directory slot. That layout
opens D2 automatically with a *.PRG mask. The CLOCK.ACC, CALC.ACC and
CONTROL.ACC directory aliases are named .ACX to disable startup accessories
and leave enough VDI workstations for QED and CFLIB. No executable or resource
payload has been changed.
QED is not present in this cartridge.

qed.atr is a new MyDOS-format disk populated with the original release's
QED.PRG, QED.RSC, QED.TXT, QEDLGPL.TXT and QEDAPACH.TXT, plus SAMPLE.TXT and
QED.CFG. The configuration sets normal window dimensions,
fixed font size and the internal clipboard without changing QED code.
