## Application permission

As an additional permission under section 7 of GPL version 3, the Exec816
copyright holders permit independent applications to use Exec816's documented
public interfaces, including the COP gateway, message/device interfaces and
exported resident services, under licences of the application authors' choice.
This permission applies whether an application is loaded separately or bundled
with Exec816 in the same boot image.

An independent application does not incorporate or derive from GPL-covered
Exec816 implementation code, apart from using these interfaces. It may include
the MIT bindings and helpers listed above. Merely using public interfaces or
sharing a boot image does not require the application's code to be licensed
under GPL. The Exec816 portions of a combined distribution, and modifications
to those portions, remain subject to GPL version 3. This permission does not
grant rights to third-party code.

under `toolchain/`. Historical qualification records retain their original
hashes and do not constitute a new licensing grant for third-party material.
