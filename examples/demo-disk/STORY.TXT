Exec816 at work

Small commands, real files and tasks.
Programs load from disk into upper RAM.
When they finish, their streams close
and their memory returns to the system.

Read this guide a page at a time:
  MORE SYS:STORY.TXT
Space advances a page, Return one row,
and Q returns to the shell.

Commands live in SYS:C, named by C:.
The default PATH searches the current
directory, then C:. File arguments use
the current directory. PATH lists the
search path; PATH RESET restores it.

CAT reads files; TYPE shows plain text.
WC counts lines, words and bytes. A pipe
joins two programs while other tasks
can run. Try:
  HELLO | WC
  CAT SYS:STORY.TXT | WC
CAT accepts several exact filenames:
  CAT SYS:STORY.TXT SYS:README.TXT | WC
Use < to select Input and > for Output:
  WC <SYS:STORY.TXT
  ECHO saved >WORK:OUT.TXT
  ECHO more >>WORK:OUT.TXT

DIR lists a directory. LIST also accepts
simple * and ? filename patterns:
  LS SYS:*.TXT NAMES
LS is a preset alias for LIST. Patterns
are handled by commands, not expanded
by the shell. CAT accepts up to eight
exact files. COPY and DELETE also accept
patterns with up to eight selections.

HEAD selects the start of a file; GREP
finds literal text, with optional case
folding and line numbers:
  HEAD SYS:STORY.TXT LINES 5
  TAIL SYS:STORY.TXT LINES 3
  GREP shell SYS:STORY.TXT NOCASE NUMBER
FIND searches filenames in subdirs:
  FIND SYS: PATTERN *.TXT
CMP compares files. CKSUM checks bytes
and length; HEXDUMP shows their values:
  CMP SYS:STORY.TXT SYS:STORY.TXT
  CKSUM SYS:STORY.TXT
  HEXDUMP SYS:STORY.TXT LENGTH 32

SYS: is read-only. WORK: is writable.
RAM: holds temporary files in memory:
  ECHO a quick note >RAM:NOTE.TXT
  CAT RAM:NOTE.TXT
  CP SYS:STORY.TXT RAM:
RAM: also supports folders, append,
pipes and EXECUTE scripts. It grows as
needed and loses its files on reboot.
DELETE frees their memory.
MKDIR and CP are preset aliases for
MAKEDIR and COPY. COPY accepts a filename
or existing folder as its destination:
  MKDIR WORK:NOTES
  CP SYS:STORY.TXT WORK:NOTES
  CP SYS:STORY.TXT WORK:NOTES/ONE.TXT
COPY SYS:STORY.TXT . copies to the
current folder, keeping STORY.TXT.
Copy several files to a folder:
  CP SYS:*.TXT RAM:
  DELETE RAM:*.TXT
COPY skips folders when matching. A
pattern needs an existing target folder.
COPY and DELETE collect names first;
a ninth match or no matches fails before
any changes. Patterns stay in one folder.

ASSIGN gives a directory a logical name:
  ASSIGN DATA: WORK:NOTES
  RENAME DATA:ONE.TXT DATA:TWO.TXT
  CMP SYS:STORY.TXT DATA:TWO.TXT
RENAME stays within the same directory;
give its destination the full name.
ASSIGN lists mappings; ASSIGN DATA:
removes this one. C: is also an assign.

TEE copies Input to a file and Output:
  HELLO | TEE WORK:LOG.TXT
  HELLO | TEE WORK:LOG.TXT APPEND
COPY and TEE create or truncate files;
APPEND preserves their previous bytes.
DELETE removes files or empty folders:
  DELETE DATA:TWO.TXT DATA:STORY.TXT
  DELETE WORK:LOG.TXT
  ASSIGN DATA:
  DELETE WORK:NOTES

CD prints the current directory. CD ..
or CD / moves to the parent; CD : goes
to this volume's root. CD .. stays at
root if there is no parent. Other paths
do not support . or .. components;
COPY accepts . as its destination.

ALIAS lists the current definitions.
MKDIR, LS and CP leave five free slots.
Replace or remove them, or add your own:
  ALIAS SAY "ECHO hello"
  SAY world
  UNALIAS SAY
Aliases last for this shell session.

EXECUTE runs a file of shell commands:
  EXECUTE WORK:SETUP.TXT
Each line uses normal aliases, pipes
and redirection. Blank lines and lines
starting with ; are ignored. Errors or
BREAK stop the script; WARN continues.
Script input is separate from command
Input. CD, PATH and aliases persist.
One script at a time; no arguments or
conditionals. EXIT also exits the shell.

S: names SYS:S, the scripts directory.
Boot runs S:STARTUP, then S:USER before
the prompt. Both are optional. Put local
aliases and assigns in S:USER. The demo
files contain comments only; edit them
in the system disk source to customize.
C: and S: leave two free assign slots.
Run EXECUTE S:USER to repeat setup.

Ctrl-A/E move to the start/end. Ctrl-B/F
or Atari left/right move across the
line. Ctrl-U clears, Ctrl-K cuts the
tail, and Ctrl-W cuts a word. Ctrl-P/N
or Atari up/down browse the last ten
commands.

CLS clears the screen and homes the
cursor. HELP lists builtins; a command
followed by ? shows its argument help.
MEM, TASKS, VER, MOUNT and DEVICES show
memory, tasks, version, disks and
drivers.

Try CAT LONG.TXT | WC and press BREAK.
The foreground command stops and the
shell returns to its prompt. EXIT or
Ctrl-D closes the shell. A useful
system should also know how to stop.
