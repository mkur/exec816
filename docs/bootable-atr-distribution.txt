Exec816 @VERSION@ system distribution
==================================

Preferred FujiNet boot: mount exec816.atr writable in D1 and boot it.
The same ATR contains OF816, the kernel, commands, applications and WORK.
No D8 disk is required. Keep a backup: saved programs and settings modify it.
QED is supplied separately from this package.

Use the included AltirraOS 65816 ROM, Atari 800XL PAL, 65C816 at 14.28 MHz,
shadow ROMs enabled, 64K base RAM plus 4032K high RAM. Disable SIO Patch,
D: burst I/O and fast boot. Use Generic + 57600 baud disk emulation.
@DISPLAY_REQUIREMENTS@

Boot transport disables internal BASIC and reopens the pinned ROM's text
screen above Exec's Task pools when necessary. Holding OPTION to keep BASIC
off is unnecessary once the disk reader starts. Arbitrary external cartridges
cannot be disabled generically; remove them unless booting the supplied
Atarimax image. That loader switches its own cartridge off before Exec entry.

All three launch choices use the same writable exec816.atr and WORK directory:
  ATR: mount it in D1 and cold-boot (preferred on FujiNet).
  XEX: load Exec-of816.xex with exec816.atr still mounted in D1.
  Cart: cold-boot the supplied Atarimax CAR with exec816.atr in D1.
The local launch-altirra.command, launch-xex.command and launch-cart-new.command
select these routes and reuse the same private writable disk copy.

FujiNet virtual-XEX boot uses its D1 slot for the XEX transport. For that route,
put exec816.atr writable in D2, interrupt the OF816 countdown, then enter:
  decimal
  2 SYSTEM-DRIVE!
  EXEC816
The ATR contents are unchanged.

Leave the keyboard alone for OF816's five-second countdown, or press a key
to enter Forth and type EXEC816 when ready. Keep the disks attached in Forth.
Kernel initialization first prints its Exec version and source identity,
including in quiet mode. Verbose startup then prints the live ROM CRC32,
firmware profile and SDX ROM installation result before VBI/IRQ=OK.
SYS: and D1: name the same writable volume on the default route. C: contains
commands, S: startup scripts, and WORK: names SYS:WORK. RAM: is temporary.

Ported SpartaDOS X tools MD5, ARC and EDX, their manuals and ARC overlays are
installed in SYS:C. Command names work with or without .COM. Try:
  CD WORK:
  MD5 ABC.TXT
  MD5 /C CHECK.MD5
  ARC
  ARC L SAMPLE.ARC
  EDX EDIT.TXT
EDX: Ctrl-S saves; Return confirms the name; Escape exits. EDX bell and live
resize are unsupported. The supplied MD5/ARC fixtures and editor text are in
WORK. Only the pinned ported binaries are supported; see the utility notice.

WORK files and desktop preferences survive cold boot. Final EXIT restores the
OS display; cold-reset to start again. BOOT.LDR and EXEC816.XEX are protected.
When updating, keep your old writable ATR and copy its WORK files into the new
image. Package refreshes do not migrate user files automatically.

The ROM loads the small reader at its own speed. The reader then synchronizes
with FujiNet and negotiates 57600 baud, including when XLOS booted it at high
speed. Interactive Forth gets standard-speed ROM I/O; EXEC816 resumes fast
loading. Keep FujiNet's HSIO index at 8 for native disk access. A failed transfer
parks with an error and requires reset. --boot-sio standard selects a slower
boot comparison/recovery reader; it does not change native storage's profile.
Development checks and physical hardware qualification are separate.

Firmware compatibility
----------------------

The adapter recognizes AltirraOS and names stock XLOS816F 2.48 and 2.49.
Other ROM images continue as XLOS (assumed), printing their actual CRC,
original vectors and section checksums even in quiet mode. A different CRC
alone no longer causes halt $0002. Mapping/state failures still halt with
their reason; include the early Exec identity and ROM block in a fault report.
Use your own XLOS ROM; it is not included. CPU, RAM and VBXE requirements
remain the same. Executed firmware checks cover the pinned stock ROMs;
third-party native/PBI extensions and physical hardware need separate checks.
