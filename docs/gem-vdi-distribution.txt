Exec816 optional interactive GEM/VDI demo

The main Exec-of816.xex still starts OF816 and, after five seconds, the standard
shell/prime demo. This optional program must be selected explicitly. It is not
a desktop or an AES application environment.

1. Cold-reset into the supplied altirraos-816.rom with BASIC disabled.
2. Select Atari 800XL, 64 KiB base RAM plus fifteen CPU high banks, 65C816 at 8x,
   shadow ROM and PAL. Enable VBXE full FX 1.26 at $D600, private 512 KiB VRAM,
   no shared RAM and no VBXE IRQ. Other cores/bases are unsupported.
3. Mount gem-vdi/graphics.atr as drive 1. Select physical generic56k disk emulation:
   SIO patch OFF, burst OFF, random delay OFF and accurate sector timing ON.
4. Load gem-vdi/Exec-gem-vdi.xex directly, not as a shell command. The application
   displays a text field, Count and Exit buttons while root reads a cold 2 KiB
   file. Tab changes focus. Printable keys and Backspace edit the field; Return
   activates a button. Count changes the number and colored indicator.
   Escape or BREAK exits from any control. Disk completion leaves the scene open.
5. On exit it restores text, displays completion for five seconds and returns
   to the OS. A media error also restores text and names the required
   gem-vdi/graphics.atr disk. The root system.atr is for the standard demo.
   If the error says "SIO offline; reset required", cold-reset after correcting
   the mounted disk. The uncertain serial transaction cannot return to the OS.

Use a cold inactive graphics baseline; do not chain-load this program over
another VBXE owner. A permanently busy blitter deliberately parks for reset,
retaining its live resources. Do not resume such a fault as an ordinary return.
To run the standard demo again, restore its no-add-ons profile, mount the main
system.atr and boot the main Exec-of816.xex.

Supported drawing: 640x240, sixteen colors, built-in 8x8 text, polylines, solid
bars, clipping, clear/update, basic color setters, solid fill and replace mode.
Native keyboard input is supported. The renderer has a fixed software cursor;
pointer/button injection is a development test and is absent from this artifact.
There is no physical mouse, AES, desktop, GEMDOS, virtual workstation, loaded font
or multiple GUI clients. Recorded small keyboard redraws take at most 12 raw /
11 optimized PAL ticks during physical SIO. Evidence is development testing on the pinned emulator;
it is not physical-hardware or full-system qualification.
