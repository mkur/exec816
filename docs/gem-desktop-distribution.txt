Exec816 colour GEM desktop
=========================

A 640x240 colour desktop, folder windows and the native shell.
Warm grey surfaces, blue-teal icons and patterned active titles give it an
Exec816 identity inspired by GEM and Workbench.
Panel, Calculator, Text and Counter launch on demand. No prime Task is started.

Boot in AltirraSDL
-----------------

Requires AltirraSDL: https://github.com/ilmenit/AltirraSDL
Upstream Altirra will not run this build.

Extract this ZIP into one folder. In System > Configure System, select:

  Atari 800XL, PAL; 65C816 at 14.28MHz (8x).
  Shadow ROMs in fast RAM enabled.
  Memory: 64K base plus 4032K high memory (63 banks), giving 4MB total.
  Firmware: included altirraos-816.rom, registered as XL/XE OS.
  Internal BASIC disabled.
  VBXE FX 1.26 at $D600, with private 512K VRAM.
  Input: ST mouse on joystick port 1; left button.
  SIO Patch and D: burst I/O disabled.
  "Unload disks when booting new image" disabled.

1. Mount @SYSTEM_DISK@ in D1 with "Generic + 57600 baud" emulation.
   Mount a disposable copy of work.atr in D8, writable.
2. Boot Exec-of816.xex; leave the keyboard alone for the five-second countdown.
3. Wait for SYS: ready and the desktop. Both matching disks must stay mounted.

Press a key during the countdown for OF816; EXEC816 resumes desktop startup.

Use the desktop
---------------

Click a window to focus it; drag its title to move it. The focused window's
name stays at the left of the menu bar; click it for Next window and Close.
Application menus follow it. Windows at the far right of the top bar
reaches covered windows. Ctrl-Tab cycles; Ctrl-Escape opens Windows.
The active application's menu is at the left. Ctrl-Shift-Escape enters it;
arrow keys/Tab and Return select. Escape dismisses menus or cancels drags.

Double-click SYS:, WORK: or C: to open a folder. Desk > New Window opens another;
up to three folders share one application Task. Closing the last folder leaves
the desktop alive. View chooses Icons/List; Sort by name toggles name/disk order. Select then
Return, or double-click, to open one entry. Shift-click toggles multiple entries;
Shift-arrow adds an entry. Ctrl-A/View > Select All includes cached offscreen
entries; View > Select None clears. Open and Rename need one entry.
Arrows navigate; a dotted outline marks keyboard focus. Selection reverses the
label without changing the icon. File > Parent or Esc goes to the parent in the same window; at a volume root
Esc does nothing. File > Refresh or Ctrl-L reloads the directory.
The thin top line shows totals, selection counts or operation feedback. The path
is in the title. New windows start smaller; navigation preserves their size.
Drag the bottom-right size gadget; vertical arrows, track and thumb scroll.
The top-right fuller toggles full/remembered size. Listings retain 256 entries
and reuse up to sixteen visible objects; larger listings report truncation.

Path (P), New Folder (N) and Rename (R) open inline text dialogs. Tab changes
focus, Return accepts, Escape/Cancel dismisses. Names fold to uppercase.
Use WORK: for writes; SYS: is read-only. File > Copy copies a regular-file
selection: one file asks for a full destination path, several ask for a directory.
Drag a selected file to another folder window to copy the selection. Drop on
empty content or a directory icon/row. Move four pixels to start; Escape cancels.
Directories cannot be dragged. The target status strip names the destination.
Existing targets offer Replace/Skip/Cancel (Cancel is the default). Copy reuses
one 16 KiB buffer. Cancel/Escape removes the current partial EXECCOPY.TMP;
completed files stay copied. Cancellation waits for the current disk operation.
An existing destination is preserved until copying ends.
The final replacement is not atomic: if rename fails, recover EXECCOPY.TMP from
the target directory. A pre-existing EXECCOPY.TMP blocks copying.
File > Delete confirms the selected count, then deletes files/empty directories
in order. Both commands stop on the first error. Completed work stays done;
pending deletions stay selected. One batch runs at a time. Closing its folder
or quitting cancels it. Other folders can browse; an open text dialog keeps its
typed input when a completed batch refreshes affected views.

Desk launches Control Panel, Calculator, Text or Counter. Folder closure leaves
these applications running. The panel offers Off/Mild mouse acceleration and
Apply/Defaults/Cancel; Tab, Space and Return operate its controls.
TXT files open in Text. Other files launch as programs, with output in the shell.
Close applications to release scarce Task/window slots. Desk > Quit Desktop
stops its children. Shell EXIT stops the desktop and returns to the OS.

Desk > Save Settings writes WORK:DESKTOP.CFG. Keep the writable disk to restore
folder paths/sizes, view/sort, mouse preference and file associations next boot.
There is no autosave. The default association is TXT -> C:TEXT.APP.

Shell examples
--------------

Click the shell title before typing. Try TASKS, DIR, HELLO or CAT STORY.TXT | WC.
A pipeline needs two free Task slots. BREAK cancels a command.
RUN C:FILES.APP opens standalone Files; its Stop/close still collects its child.
RUN C:TEXT.APP "SYS:VIEW.TXT" opens the read-only viewer: O opens another file,
Up/Down scroll, Space/Shift-Space page, Escape cancels loading, Q quits.
Limits: 64 KiB and 4096 lines; no wrapping/horizontal scrolling.
RUN C:CALC.APP starts the integer calculator. Digits and + - * / = C work;
Return is equals. Keep SYS:CALC.RSC on the system disk.
RUN C:DIALOG.APP demonstrates editable forms, alerts and the standard selector.
RUN C:G4BENCH.APP runs the adapted drawing benchmark: Return starts, Escape
stops/closes. Keep it uncovered. Results go to WORK:G4BENCH.TXT.

This is a development preview. Dragging icons, recursive
file operations, trash, horizontal scrolling and additional icon artwork are future
work. The standard non-GUI distribution still boots the shell/prime demo.
