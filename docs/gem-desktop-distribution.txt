Exec816 GEM desktop
==========================

A GEM Control Panel, counter, Files browser and native shell.
No prime task is started.

Boot in AltirraSDL
-----------------

Requires AltirraSDL: https://github.com/ilmenit/AltirraSDL
Upstream Altirra will not run this build.

Extract this ZIP into one folder. In System > Configure System, select:

  Atari 800XL, PAL; 65C816 at 14.28MHz (8x).
  Shadow ROMs in fast RAM enabled.
  Memory: 64K base plus 4032K high memory (63 banks), giving 4MB total.
  Firmware: the included altirraos-816.rom, registered as XL/XE OS.
  Internal BASIC disabled.
  VBXE FX 1.26 at $D600, with private 512K VRAM.
  Input: ST mouse on joystick port 1; left button.
  SIO Patch and D: burst I/O disabled.
  "Unload disks when booting new image" disabled.

1. Mount @SYSTEM_DISK@ in D1: with "Generic + 57600 baud" emulation.
   Mount a disposable copy of work.atr in D8: with writes enabled.
2. Boot Exec-of816.xex and leave the keyboard alone for the five-second countdown.
3. Wait while the native loader reads GEMSYS.BIN from the system disk, then
   for SYS: ready, the shell prompt and the three GEM windows.

Both disks are required at startup. Keep these matching disks mounted throughout
the session. Press a key during the countdown to enter OF816 instead; EXEC816
continues into this desktop. The shared GUI loads once before the graphical
console starts; drawing does not reread it from disk. Use the matching system
disk: a missing or mismatched GEMSYS.BIN prevents desktop startup.

Use the desktop
---------------

Click a window to bring it forward. Drag application titles to any on-screen pixel
position below the menu bar; shell moves use its character grid. Escape cancels
a title drag. The top-left menu belongs to the active application. Files offers
Open, Refresh, Stop, Quit, Path, New Folder and Rename. Windows lists every open window, including covered
ones and the shell, with Next window and Close below when Files is active.
Other windows offer Next window and Close in the top-left menu.
Ctrl-Tab / Ctrl-Shift-Tab cycle windows. Ctrl-Escape opens Windows; Tab or arrow
keys and Return select an entry. Ctrl-Shift-Escape enters an application menu;
Left/Right changes headings, Tab/Shift-Tab or Up/Down changes entries, and Return
selects. Click a title then an entry, or drag and release on an entry. Escape or
a click outside cancels the menu. Disabled actions cannot be selected.
Click the boxed closer at the left of the title or use Close to close an application. Focus returns to the frontmost
remaining window. Close is disabled for the shell; use EXIT to end the session.
The panel controls mouse acceleration through its own GEM object tree.
Off gives fixed 2x movement; Mild gives slow precision and faster travel.
Select a radio button, then Apply; Defaults stages Mild. Cancel discards pending
edits and restores the active session choice. Closing discards pending edits;
reopening reads the active choice. Settings last until the desktop restarts.
Tab/Shift-Tab move focus, Space activates focus and Return activates Apply. Escape/BREAK cancels a held press. Release
outside a button to cancel it. The counter continues independently.
@POINTER_DESCRIPTION@

Files loads its interface from DESKTOP.RSC on the system disk. Select a row and
press Return to enter a folder or launch an Exec command. Up returns to the parent;
Refresh reloads the directory and retains the selected filename. Drag the lower-right
size gadget to change the view. Arrows move one row, track clicks one page, and the
thumb scrolls continuously. Files caches up to 256 entries, shows up to sixteen
rows, and reports when a listing exceeds that limit.
Path (P), New Folder (N) and Rename (R) open text dialogs inside the Files window.
Use WORK: for writes. Type a directory path or one folder/file name; the fields
fold letters to uppercase for the current disk formats. Tab/Shift-Tab changes
focus; Return accepts, Escape or Cancel dismisses. You can also click OK/Cancel.
Errors keep the dialog and text available for correction. Other windows remain
usable. Closing Files while editing follows its normal child-cleanup path.
File inside the window (or F) retains the Open/Refresh/Stop/Cancel popup.
Use Tab or Up/Down and Return in that popup; Escape cancels. Launched commands
have no arguments or keyboard input; their output appears in the shell. Stop
requests native BREAK or a GEM window close. Try opening C and launching HELLO
or TICK. TICK prints periodically until Stop. PANEL.APP, COUNTER.APP and
FILES.APP are independently loadable GEM applications.
CALC.APP is the GEM4XE integer calculator. Close Panel, then open C in Files
and launch CALC.APP, or type RUN C:CALC.APP in the shell. Keep SYS:CALC.RSC
on the system disk. Digits, +, -, *, /, = and C work from the keyboard;
Tab/Shift-Tab move focus, Space activates it and Return is equals.
Use +/- to change sign. Division truncates toward zero. Values range from
-2147483647 to 2147483647; excess entry, overflow and division by zero leave
the displayed operand unchanged. Quit or X closes it; Files' Stop does too.
DIALOG.APP demonstrates standard GEM dialogs. Close Files or Panel, then type
RUN C:DIALOG.APP. Continue accepts the initial alert before the app window opens.
Edit (E) opens a text form; Apply accepts and keeps editing, Done returns to the
app. Alert (A) asks Keep/Back. Quit (Q), the Dialog menu or the closer exits.
Open (O) and Save (S) choose a directory/filter and filename. Save only selects
a name; it does not write a file. Try SYS:SELECT/*.TXT for a multi-page list,
or SYS:SELECT/SUB/*.TXT and Up for navigation. Edit Path and press Return to
apply it; Escape cancels. RUN C:DIALOG.APP SELECT also opens the selector before
the application's own window, after the initial alert.
Tab/Shift-Tab traverse controls, Return activates the default, and Space activates
a focused button. Release outside cancels a press. Other windows keep running.
Moving or choosing a menu command while editing returns to the application's
normal event loop, preserving the typed text. Closing during a form exits cleanly.

PRIMES needs tiled-console mode and cannot run in this desktop. Closing Files stops
and collects its running child. Close an existing GEM window before launching
another GUI app when all four desktop windows are occupied.

With all three GEM windows open, one Task slot remains for a disk command.
Close one GEM window before running a two-command shell pipeline.
Click the shell title before typing. Try TASKS, DIR, CAT STORY.TXT | WC, or
CAT LONG.TXT. BREAK cancels a running command. SYS: is read-only; WORK: is a
disposable writable disk. EXIT closes all GEM applications and returns to the OS.
The shell collects closed initial applications while waiting at the prompt.
After closing Files, type RUN C:FILES.APP to start it again. The same RUN command
can launch PANEL.APP or COUNTER.APP; the shell supports one background job.

This is a desktop development preview. Files and the text viewer resize and scroll;
the other example windows retain fixed geometry. Horizontal scrolling, cascading menus
and file-manager icons remain future work.

Read text files
---------------

Close one GEM application to free a window, then type RUN C:TEXT.APP.
RUN C:TEXT.APP "SYS:VIEW.TXT" opens the included introduction directly.
Files also opens TXT entries in this viewer. Files owns that child: Stop
closes it, and closing Files stops and collects it before Files exits.

File > Open or O opens the standard selector. Up/Down move one line; Space
and Shift-Space move a page. Use the vertical arrows, track or thumb to scroll
and the bottom-right gadget to resize. Escape or File > Cancel Load abandons
a pending replacement between disk reads. Q, File > Quit or the closer exits.
The shell and counter continue running during loading and drawing.

The viewer is read-only: at most 64 KiB and 4096 lines, without wrapping or
horizontal scrolling. LF, CR, CRLF and ATASCII EOL delimit lines. Tabs use
eight-column stops; other nonprinting bytes appear as dots. Cancel and failed
Open preserve the current document and scroll position. Try STORY.TXT or
LONG.TXT for more scrolling. Opening a new GUI app still requires a free slot.
