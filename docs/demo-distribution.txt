Exec816 demo
============

A text shell and an independent prime search share the screen. Try disk
commands and pipes while the prime search keeps running.

Boot in AltirraSDL
-----------------

Requires AltirraSDL: https://github.com/ilmenit/AltirraSDL
Upstream Altirra will not run this build.

These steps use AltirraSDL's desktop interface. Extract all files from this
ZIP into one folder. Open System > Configure System... and select these
pages in the settings window's left-hand tree:

Computer > System
  Hardware type: Atari 800XL
  Video standard: PAL

Computer > CPU
  Select 65C816 (14.28MHz), which is 8x speed.
  Check "Shadow ROMs in fast RAM".

Computer > Memory
  Memory Size: 64K
  High memory banks: 4032K (63 banks above the base RAM).
  Select the 65C816 CPU first to enable this control.

Computer > Firmware
  Click Firmware Manager... > Add... and choose altirraos-816.rom.
  In Edit Firmware Settings, name it "Exec816 AltirraOS", set Type to
  "XL/XE OS", and click OK. Close the Firmware Manager, then select
  "Exec816 AltirraOS" in Operating system.
  Uncheck "Enable internal BASIC (boot without Option pressed)".

Computer > Acceleration
  Uncheck "SIO Patch" and "D: burst I/O".

Computer > Boot
  Uncheck "Unload disks when booting new image" so the system disk stays
  mounted when you boot the XEX.

Close the settings window, then:

1. Open File > Disk Drives... and click the "..." button on the D@SYSTEM_DRIVE@: row
   to select @SYSTEM_DISK@.
2. In the same Disk drives window, set Emulation level to
   "Generic + 57600 baud". This setting applies to all drives.
3. Choose File > Boot Image... and select Exec-of816.xex. Leave the keyboard
   alone; Exec816 starts after the five-second countdown.

The ATR contains the system files. Boot the XEX, not the ATR.
To enter the OF816 Forth monitor, press a key during the countdown.
Type EXEC816 to continue into the demo.

Try it
------

Wait for the SYS: ready message and the > prompt, then enter these in order.
TASKS comes first so the boot messages remain visible beside the task list:

    TASKS
    MOUNT
    CD SYS:
    DIR
    HELLO
    TYPE README.TXT
    MEM
    HELLO | WC
    CAT STORY.TXT | WC

HELLO | WC prints 1 3 17. CAT STORY.TXT | WC prints 24 133 746.
The columns count lines, words and bytes. The lower screen shows the
prime search advancing independently.

Type HELP to list the shell's built-in commands:

    HELP ECHO CD DIR TYPE MEM TASKS VER MOUNT DEVICES EXIT

The disk also includes CMP, CKSUM, HEXDUMP, HEAD, GREP, LIST and MORE.
Try HEAD STORY.TXT LINES 5, CKSUM STORY.TXT, or LIST NAMES.
MORE LONG.TXT pages text: Space advances a page, Return a line, Q quits.
GREP shell STORY.TXT NOCASE searches literal text; there is no regex.

Try CAT LONG.TXT | WC, then press BREAK to cancel it. EXIT stops the demo
and restores the OS display. Disk access is read-only; keep the same disk
mounted until reset. Pipes support two external commands.
