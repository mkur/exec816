# Exec816 0.2.3 — XLOS SIO handover and boot diagnostics

[Release notes](README.md)

This patch restores high-speed boot loading when XLOS has already left the
peripheral at 57,600 baud. The shared ATR/XEX reader confirms standard-rate
communication before negotiating its bulk-read speed. Recovery remains
bounded, and explicit standard-speed loading uses the same synchronization.

Kernel initialization now prints its version/source identity before Task and
heap setup, including in quiet mode. Verbose startup reports the live ROM
CRC-32, firmware profile and SDX installation result. Uncatalogued CRC/vector
combinations continue as `XLOS (assumed)` and print original interrupt vectors
and section checksums. Mapping and repeated-install failures retain distinct
causes and preserve the original halt reason. See the
[firmware contract](../reference/sdx-firmware.md) for the supported boundary.

The local ATR launcher now selects AltirraSDL's writable disk loader. Its
previous `--run` selection treated ATR bytes as a program and could produce
garbage and sound before OF816 started. Local XLOS ATR shortcuts use the same
correction.

## Downloads and update

Download **exec816-demo.zip** for the combined writable `exec816.atr`, matching
OF816 XEX and Atarimax images, bundled AltirraOS 3.44/65816 ROM, short guide,
notices under `licenses/` and checksums. The GEM desktop, windowed Shell,
FastBasic workbench and ported MD5/ARC/EDX tools remain included. QED is supplied
separately. XLOS ROMs are not redistributed.

Use a fresh ATR and preserve your existing writable disk. Copy your WORK files
into the new image. For FujiNet, mount the ATR **writable on D1**. XEX and
cartridge boot use that same disk; the five-second OF816 autoboot is unchanged.
Under XLOS, prefer ATR or cartridge boot because AltirraSDL's default XEX loader
fails before Exec entry. Source-built local launchers use a persistent private
writable disk copy; see the [build guide](../contributing/building.md).

**exec816-fastbasic-source.zip** supplies the matching Exec source and pinned
patched FastBasic donor tree. Both downloads have separate SHA-256 files.
The clean release build displays **Exec816 0.2.3 (v0.2.3)** at startup and in
`VER`. Existing 0.2.2 tags and assets are preserved.

## Validation and limits

The [ROM diagnostics evidence](../history/kernel-rom-diagnostics.md) and
[SIO handover evidence](../history/boot-only-fast-sio.md#xlos-speed-handover-correction)
record the implementation checks and exact pinned inputs. The prepared
candidate also records its executed checks and package hashes separately.

Reserved bank-zero growth is **0 fixed/root/kernel bytes, 0 bytes per each of
twelve public Tasks and 0 idle bytes**, including guards, alignment and unused
capacity. The diagnostics buffer and initial SIO call use existing stack
reservations; no Task pool or loading arena grows.

This remains a **preview**, with full hosted-system/release qualification
pending. Physical accelerator/cartridge hardware, physical FujiNet UART timing
and XLOS CONFIG/OPTION boot remain unqualified. Arbitrary OS high-memory
allocations and third-party PBI/native interrupt handlers remain unsupported.
Editor latency targets, source debugging and native BASIC graphics remain open.
