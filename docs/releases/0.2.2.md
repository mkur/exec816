# Exec816 0.2.2 — XLOS boot fix

[Release notes](README.md)

This patch fixes startup with **Drac's stock XLOS816F 2.48 and 2.49**.
Exec816 0.2.1 could reach OF816 and load the kernel, then halt with
`KERNEL READY=$0000` and `System halted: $0002`. Its SDX adapter accepted only
the bundled AltirraOS ROM and contained firmware-specific interrupt destinations.

The adapter now identifies the running ROM, captures its original IRQ/NMI
destinations and installs the matching reversible ROM shadow. Public console
I/O uses the reviewed shared stack path on both firmware families. The patch
adds no reserved bank-zero memory, fixed or per Task.

The **included AltirraOS 3.44/65816 ROM remains the default**. XLOS is not
redistributed; supply your own exact supported F image. Other versions,
customized ROMs and A variants are not admitted. Exact hashes and limits are
in the [firmware contract](../reference/sdx-firmware.md).

## Downloads and update

Download **exec816-demo.zip** for the combined writable `exec816.atr`, matching
OF816 XEX and Atarimax images, bundled AltirraOS ROM, short guide, notices under
`licenses/` and checksums. MD5, ARC, EDX and the FastBasic workbench remain on
the system disk. QED is supplied separately.

Use a new copy of the ATR for this update. Preserve your existing writable disk
and copy its WORK files into the new image. For FujiNet, mount the new ATR on
**D1 with write permissions enabled** so that `WORK:` remains writable.
The combined disk and five-second OF816 autoboot are unchanged. XEX and
cartridge boot use that same system ATR. Under XLOS, prefer ATR or cartridge
boot; AltirraSDL's default XEX loader fails before Exec entry.

`exec816-fastbasic-source.zip` supplies the Exec source and patched FastBasic
donor tree. Both downloads have separate SHA-256 files. The clean release build
displays **Exec816 0.2.2 (v0.2.2)** at startup and in `VER`.

## Validation and limits

The fix has development coverage on pinned AltirraSDL 65C816/PAL configurations:
656 host tests, native ROM/context and COP checks, shadow installation/removal,
minimum-stack scrolling, MD5, ARC help/archive operations, EDX editing/save,
retained FastBasic state/reset, native SIO/peer progress, cancellation and cleanup.
Combined-ATR boot passes on both XLOS versions and AltirraOS; the new Atarimax
route also passes on XLOS 2.48F. Input hashes, cases and exclusions are in the
[implementation evidence](../history/xlos-sdx-support.md).

This remains a **preview**, with full platform/release qualification pending.
The development checks do not qualify physical accelerator hardware or
FujiNet CONFIG/OPTION boot under XLOS. Arbitrary OS high-memory allocations and
third-party PBI/native interrupt handlers remain unsupported. Existing editor
latency targets, source debugging and native BASIC graphics remain open.
