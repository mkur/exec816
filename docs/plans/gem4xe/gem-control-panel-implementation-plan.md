# GEM Control Panel implementation

[Design](gem-control-panel-design.md) · [Plans](../README.md)

1. Add the compiled-in tree and ordinary GEM application body, including
   release/cancel, radio peers, keyboard focus and damaged-object drawing.
2. Compose one panel and one existing counter with a resident lifecycle wrapper
   and a shell demo profile. Keep default demo behavior and OF816 packaging.
3. Run a focused emitted physical-input session: pointer and keyboard actions,
   disabled control, outside-release cancellation, move/overlap/redraw, counter
   progress, close and shutdown with stack/ownership/heap checks. Build the
   distributable and cold-boot its exact image. Record scope and commit.
