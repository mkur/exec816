Exec816 standard text shell
===========================

A full-screen 40 by 24 Atari text console and shell. No prime task is started.
VBXE is not required.

Boot in AltirraSDL
-----------------

Requires AltirraSDL: https://github.com/ilmenit/AltirraSDL
Upstream Altirra will not run this build.

Extract this ZIP into one folder. In System > Configure System, select:

  Atari 800XL, PAL; 65C816 at 14.28MHz (8x).
  Shadow ROMs in fast RAM enabled.
  Memory: 64K base plus 4032K high memory (63 banks), giving 4MB total.
  Firmware: the included altirraos-816.rom, registered as XL/XE OS.
  Internal BASIC disabled.
  SIO Patch and D: burst I/O disabled.
  "Unload disks when booting new image" disabled.

1. Mount the included @SYSTEM_DISK@ in D@SYSTEM_DRIVE@: using File > Disk Drives.
   Select "Generic + 57600 baud" as the disk emulation level.
   Mount a disposable copy of work.atr in D8: with writes enabled.
2. Use File > Boot Image to start Exec-of816.xex.
3. Leave the keyboard alone for the five-second OF816 countdown.
   Exec816 then loads with progress dots and the text shell opens
   automatically; wait for SYS: ready and the > prompt.

Boot the XEX; the ATR supplies its system files. Keep this matching disk
and work.atr mounted for the whole session. A disk from another build can contain
incompatible commands.

Press a key during the countdown to enter OF816 instead. Type EXEC816
to resume loading and continue into the text shell. OF816 appends its banner
without clearing earlier boot messages. CACHE-BLOCKS! and SYSTEM-DRIVE! settings
entered in Forth are preserved while loading resumes and the kernel starts.

Technical boot messages default on. They show memory bounds, kernel/table banks,
DP/stack placement, initialization results and any detected VBXE core revision.
Type 0 BOOT-VERBOSE! in Forth to suppress this trace, or 1 BOOT-VERBOSE! to enable
it. Boot failures remain visible in quiet mode. Exec reserves the first linear
RAM bank, $010000-$01FFFF, and starts its kernel in bank $02.
RAM ADOPT and TASK/HEAP INIT each print one OK or FAILED result. A kernel
initialization failure prints its error code and System halted, even in quiet
mode.

Try it
------

    TASKS
    DIR
    HELLO
    HELLO | WC
    CAT STORY.TXT | WC
    TYPE STORY.TXT
    MEM
    CLS
    RUN PRIMES
    JOBS

The pipelines print 1 3 17 and 108 518 3171 respectively (lines, words, bytes).
TASKS lists the shell and service workers without a primes task.
HELP lists built-in commands. BREAK cancels a foreground command.
Ctrl-L clears the screen and redraws the prompt and your current input.
EXIT or Ctrl-D closes the shell and restores the OS display.

External commands live in SYS:C. Startup assigns C: there and S: to SYS:S.
The default PATH searches the current directory and then C:.
PATH RESET restores that list.
File arguments still use the current directory. Try:

    PATH
    DIR C:
    LIST *.TXT NAMES
    LS *.TXT NAMES
    ALIAS
    ASSIGN

The disk includes HELLO, CAT, WC, CMP, CKSUM, HEXDUMP, HEAD, GREP, LIST, MORE,
COPY, TEE, DELETE, RENAME, MAKEDIR, ASSIGN and PRIMES. C: and S: use two of four
assignment slots. Before the prompt, optional S:STARTUP and S:USER run in order.
The supplied files contain comments only. Edit S/USER in the system disk source
for local setup; EXECUTE S:USER reruns it manually. Missing scripts are silent;
errors or BREAK stop startup scripts and return to the prompt.
Each new shell starts with MKDIR -> MAKEDIR, LS -> LIST and CP -> COPY.
Use ALIAS to replace them or UNALIAS to remove them; five of the eight slots
remain available for other aliases. Definitions last for this shell session.

PRIMES opens a six-row pane below the shell, leaving 40 by 18 for commands.
Only changing numbers are updated.
PRIMES PASSES 1 runs one foreground pass; physical BREAK stops a foreground run.
RUN PRIMES starts it in the background and immediately returns the prompt.
JOBS shows its identity; BREAK identity requests stop. Closing the pane restores
the full screen and preserves an edited line. RUN PRIMES PASSES 1 completes
naturally, finding 1,229 primes through 10,000, with 9,973 as the last prime.
One background job and one pane are supported. Background streams default to
NIL; file redirection is supported. EXIT stops and collects the job.

Create a directory with MKDIR WORK:NOTES. CD .. or CD / moves to the parent
and CD : to the volume root. CD .. is a shell shortcut; other paths do not
support . or .. components. CLS clears the screen and returns the prompt home.

SYS: is read-only; WORK: is writable (720 KiB, 256-byte sectors).
Try ECHO saved >WORK:OUT.TXT and
CAT WORK:OUT.TXT. Redirection creates or truncates its target when opened,
even if the command later fails. Keep SYS: on D1-D7; D8 is reserved for WORK:.

Ctrl-A/E move to the start/end; Ctrl-B/F move left/right. Ctrl-U clears the
line, Ctrl-K cuts to the end, and Ctrl-W cuts a word. Ctrl-P/N or Atari
up/down browse the ten-command history; Atari left/right move the cursor.

This is a development preview. The cooked editor
retains its 36-character editing tail.
