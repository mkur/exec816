Exec816 desktop preview
=======================

A 64 by 20 shell window and an overlapping graphical application, each on an
independent Exec Task. No prime task is started. The existing console worker
owns all presentation.

Boot in AltirraSDL
-----------------

Requires AltirraSDL: https://github.com/ilmenit/AltirraSDL
Upstream Altirra will not run this build.

Extract this ZIP into one folder. In System > Configure System, select:

  Atari 800XL, PAL; 65C816 at 14.28MHz (8x).
  Shadow ROMs in fast RAM enabled.
  Memory: 64K base plus 4032K high memory (63 banks), giving 4MB total.
  Firmware: the included altirraos-816.rom, registered as XL/XE OS.
  Internal BASIC disabled.
  VBXE FX 1.26 at $D600, with private 512K VRAM.
  Input: ST mouse on joystick port 1; left button.
  SIO Patch and D: burst I/O disabled.
  "Unload disks when booting new image" disabled.

1. Mount the included @SYSTEM_DISK@ in D@SYSTEM_DRIVE@: using File > Disk Drives.
   Select "Generic + 57600 baud" as the disk emulation level.
2. Use File > Boot Image to start Exec-of816.xex.
3. Leave the keyboard alone for the five-second OF816 countdown.
   The desktop opens automatically; wait for SYS: ready and the > prompt.

Boot the XEX; the ATR supplies its system files. Keep this matching disk
mounted for the whole session. A disk from another build can contain
incompatible commands.

Press a key during the countdown to enter OF816 instead. Type EXEC816
to continue into the desktop.

Use the desktop
---------------

Click a window to give it keyboard focus. Drag a title with the left button;
release commits the move and repairs exposed content. Escape cancels a drag.
Windows remain onscreen on an eight-pixel grid. Only the left button is supported.

Click the application and press a key: its Task performs finite computation,
then replaces the retained panel content. Its X gadget requests cooperative
closure. The shell has no close gadget: click it and type EXIT to close the
whole desktop. Closing the application first leaves the shell available.

Try these shell commands
------------------------

    TASKS
    DIR
    HELLO
    HELLO | WC
    CAT STORY.TXT | WC
    TYPE STORY.TXT
    MEM

The pipelines print 1 3 17 and 24 133 746 respectively (lines, words, bytes).
TASKS lists the shell and service workers and desktop-app, without a primes task.
HELP lists built-in commands. BREAK cancels a foreground command.
EXIT or Ctrl-D closes the shell and restores the OS display.

This is a development preview, not hardware or whole-system qualification.
Disk access is read-only. Pointer, drag outline and move repair timing targets
remain open: two-client pointer response reached 166 ms and a disk-load button
164 ms. Move repair is commonly 0.7-0.9 seconds and can exceed a second under I/O. Captured movement is correct within the tested ST envelope,
but this first desktop does not yet meet the snappy-window-interaction goal.
No resizing, menus, file browser, right button or general AES compatibility. The cooked editor
retains its 36-character editing tail, even on the wider bitmap screen.
